# Capstone 3: AI on-call assistant

> Status: planned · Builds on: Phases 4 to 6

A read-only assistant that helps an on-call engineer investigate incidents.
It lives in its own repository; this folder holds the summary and the link.

## What it delivers

- Read-only agent that uses MCP servers to query metrics, logs and the cluster
- Draft root-cause summaries for staged incidents
- An evaluation set of staged incidents with scoring
- A small open model served on the cluster, with latency and cost metrics
- Guardrails: allow-listed tools, no write access, full audit log
