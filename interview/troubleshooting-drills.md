# Troubleshooting drills

Talk through each one out loud, as you would in an interview.

1. Users report the site is slow, but CPU and memory look normal.
2. A Kubernetes deployment is stuck with pods in `Pending`.
3. Latency p99 doubled after a deploy, p50 did not change.
4. A cron job silently stopped running last week.
5. TLS errors started for some users but not others.
6. Disk is full on a database host at 3 a.m.
