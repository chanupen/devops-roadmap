# Phase 0 · Foundations

The everyday skills every later phase depends on: reading a Linux box, following a packet, and automating small jobs.

Estimated time: 2 weeks.

| Module | Labs |
| --- | --- |
| [Linux and systemd](01-linux/) | Fix a broken systemd service from its logs; Find what is filling the disk, including deleted-but-open files |
| [Networking for operators](02-networking/) | Diagnose a DNS failure with `dig`; Find why a TLS handshake fails (expired cert, wrong chain, wrong SNI) |
| [Git and GitHub flow](03-git/) | Recover a lost commit with `reflog`; Find a bad commit with `git bisect` |
| [Bash and Python scripting](04-bash-and-python/) | Write a log summariser in Bash, then rewrite it in Python; Write a health-check CLI with tests |
