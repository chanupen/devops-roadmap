# Linux and systemd: exercises

Try each one without searching first. Write down the commands you used.

1. A service starts, then stops after ten seconds with no error. What do you check?
2. `df -h` shows 40% free but writes fail with "No space left on device". Why?
3. Disk usage dropped by 0 bytes after deleting a 5 GB log file. Find the space.
4. A process ignores `kill <pid>`. What are your options, and what are the risks?
5. A host is slow. You have five minutes. Which commands, in which order?
